# CTA license copy

This folder keeps a dated copy of the CTA Developer License Agreement that was in force when the hosted instance started. CTA can change its terms, and the copy shows which terms the project agreed to.

Save the agreement here as `cta-developer-license-agreement-YYYY-MM-DD.html`, dated the day you downloaded it. CTA's GTFS zip carries a copy of the agreement as an HTML file, so the zip is an easy source.

When CTA publishes new terms, add the new copy next to the old one. Never edit or delete an older copy.
